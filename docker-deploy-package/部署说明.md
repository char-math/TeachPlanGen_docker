# 教案辅助平台 - Docker 部署说明

## 文件清单
- `dify-demo-v5-app.tar.gz`：已构建好的 Docker 镜像（本机构建，linux/amd64，无需在服务器上重新 build，也就不会再碰到 docker.io 连不通的问题）
- `docker-compose.yml`：启动配置
- `.env.example`：需要配置的环境变量清单（**不含真实密钥**，真实密钥由我们私聊单独发送）

## 部署步骤

1. 加载镜像：
   ```bash
   docker load -i dify-demo-v5-app.tar.gz
   ```

2. 把 `.env.example` 复制为 `.env`，填入真实的 Dify API 密钥（我们会私下发给负责部署的同学，不在群里发）：
   ```bash
   cp .env.example .env
   # 编辑 .env，填入真实值
   ```

3. 启动：
   ```bash
   docker compose up -d
   ```

4. 访问 `http://服务器IP:3000` 验证。

## 需要注意

- 需要开放/映射 3000 端口（或按需改 `docker-compose.yml` 里的端口映射）
- `./data` 目录用于持久化 SQLite 用户数据库，首次启动会自动创建
- 应用需要能访问 `api.dify.ai`（调用 Dify 工作流和知识库接口），确保服务器出网正常
- 镜像是在 Windows Docker Desktop 上构建的 `linux/amd64` 架构，如果服务器是 ARM 架构（如部分云厂商的 ARM 实例）需要告知我们重新构建 multi-arch 镜像
